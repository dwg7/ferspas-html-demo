この数値が何を意味するか

ASI（Agricultural Stress Index）は、衛星観測NDVI（植生指数）と地表面温度から作る VHI（Vegetation Health Index）を、作期の重要な生育段階ほど重く効くよう作物係数で加重平均し（MVHI）、 さらに「その耕地の何%が、過去の同じ暦週と比べて悪化した(VHI<35%)か」という割合に変換したもの（単位: %）。 詳しい計算過程・値の量子化・sentinel値の注意点は findings.md参照。

値が低い（緑）＝「平年並みか、それより良い」であり、「豊作」を意味しない。 この指標を実際に運用面で使っているのは、圃場の生産者というより、FAO GIEWSのような国際機関・ 各国政府の早期警戒業務の担当者であることが分かっている。日本には独自の実地調査に基づく 「作況指数」という別系統の仕組みが既にあり、本ページの目的は グローバルな早期警戒システムを、担当区域という舞台で検証することであって、 農業実務の改善を意図するものではない（docs-internal/decisions.md参照）。

2選択デカドのCOG地図表示

原資産（FAOのGCSバケット）は匿名読み取り自体が拒否される（ findings.md参照）ため、 このリポジトリがhfuさんのGoogle認証（ADC）で発行時にチェックアウトし、タイル境界（4-14-5）で クロップして再配布したコピー（derived/4-14-5-<dekad>.tif、投影変換なし）を表示する。 AOIがタイルの矩形そのものなので、境界ポリゴンによるマスクは行わず、単純な矩形クロップのみ （Italy版との違い）。色は公式SLD（ASI-D-C）の配色をそのまま使用。

選択理由・出所・制約

  • Collection・GS1/LC-C選択ロジックは、Italy版と共通。AOIの決め方だけがdwg7独自の判断である。
  • AOIはslippy-map tile z=4/x=14/y=5（空間IDの水平インデックス）の矩形（東経135.0〜157.5°、北緯40.98〜55.78°）。行政境界・地名を使わない設計判断（docs-internal/decisions.md参照）。
  • 境界ポリゴンによるマスクを行わないため、Italy版と異なり「AOI外」というNoDataは発生しない。原資産のsentinel値（251〜255）はそのまま保持される。
  • 投影変換は行っていない（原資産と同じEPSG:4326）。矩形クロップのみで、値の補間は発生しない。
  • 原資産バケット（fao-gismgr-asis-data）は匿名読み取りが拒否されるため、このcheckoutはhfuさんのGoogle Application Default Credentials（ADC）が無いと実行できない（Tier B、docs-internal/decisions.md参照）。Case 2と異なり、任意のlocal foundationが単独で再現できるわけではない。
