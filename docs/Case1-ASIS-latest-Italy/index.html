この数値が何を意味するか

ASI（Agricultural Stress Index）は、衛星観測NDVI（植生指数）と地表面温度から作る VHI（Vegetation Health Index）を、作期の重要な生育段階ほど重く効くよう 作物係数で加重平均し（MVHI）、さらに「その耕地の何%が、過去の同じ暦週と比べて悪化した (VHI<35%)か」という割合に変換したもの（単位: %）。詳しい計算過程は findings.md参照。

値が低い（緑）＝「平年並みか、それより良い」であり、「豊作」を意味しない。 VCI/VHIはその場所・その暦週の過去の記録との比較であり、絶対的な収量や生育の豊かさは表さない （疎らな植生地帯での高い値は、その環境にしては平年並みという意味に過ぎない、とFAO自身が注記している）。

この指標を実際に運用面で使っているのは、圃場の生産者というより、FAO GIEWSのような国際機関・ 各国政府の早期警戒業務の担当者であることが分かっている。日本には独自の実地調査に基づく 「作況指数」という別系統の仕組みが既にあり、本ページの目的はイタリアという既存Notebookの舞台で 忠実に再現することであって、農業実務の改善を意図するものではない（docs-internal/decisions.md参照）。

2選択デカドのCOG地図表示

原資産（FAOのGCSバケット）は匿名読み取り自体が拒否される（CORS未対応以前の問題。 findings.md参照）ため、 このリポジトリがhfuさんのGoogle認証（ADC）で発行時にチェックアウトし、イタリア国境でクロップして 再配布したコピー（derived/ITA-<dekad>.tif、投影変換なし）を表示する。 色は公式SLD（ASI-D-C）の配色をそのまま使用。地図描画ライブラリは使わず、 geotiff.jsでピクセル値を直接読み、canvasへ塗る。

選択理由・出所・制約

  • Collection・BBOX・GS1/LC-C選択ロジックは、参照Notebookのコードセルからそのまま採用した（推測ではなく実コードの値・ロジック）。Notebook自身は特定の日付ではなく「直近N日」で検索するため、このページも常に最新のデカドを検索する。
  • 「最新デカドの選択」は、Notebookの文字列インデックス処理ではなく、item のstart_datetimeとid末尾の正規表現（-GS1-LC-C）で再現している（同じ結果になるが、より頑健な実装）。
  • 国境界（Italy, ITA）は Natural Earth 10m admin-0 countries（Public Domain）から抽出した（aoi-ITA.geojson）。
  • 原資産のNoData(255)は、同じcollectionの分類コードとして「water/background」の意味も兼ねている（docs-internal/findings.md参照）。イタリア国内のpixelは元の値をそのまま保持し、国外（AOI外）だけを別の値(-1)でマスクしている。
  • 投影変換は行っていない（原資産と同じEPSG:4326）。国境ポリゴンでのクロップのみで、値の補間は発生しない。
  • 原資産バケット（fao-gismgr-asis-data）は匿名読み取りが拒否されるため、このcheckoutはhfuさんのGoogle Application Default Credentials（ADC）が無いと実行できない（Tier B、docs-internal/decisions.md参照）。Case 2と異なり、任意のlocal foundationが単独で再現できるわけではない。
